# Pipeline-PIxel-Art
Pipeline multimodale per generare sprite in pixel art con modelli di diffusione: un LLM scrive il prompt e i quesiti di verifica, ComfyUI genera le immagini, uno script le riporta a 128×128 con palette di 16 colori e un oracolo visione-linguaggio le ordina. Codice della tesi triennale.
